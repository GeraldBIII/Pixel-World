# Emberwild

A fantasy open-world 2D pixel-art game that runs in the browser. One self-contained `index.html`, no build step.

## Play

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder) to play it at `https://geraldbiii.github.io/Pixel-World/`.

## Controls

| Action | Keys |
| --- | --- |
| Walk forward / back | W S / ↑ ↓ |
| Turn (the world rotates with you) | A D / ← → |
| Attack | Left click |
| Talk, open chests | E / Enter |
| Drink potion | Q |
| Toggle map | M |
| Toggle sound | N |

On touch screens, on-screen buttons appear automatically.

## Features

- Endless procedurally generated world: meadows, forests, lakes, beaches, hills, mountains
- Day/night cycle with dynamic lighting
- Enemies: slimes, red slimes, skeletons, night-only ghosts — tougher the farther you roam
- Leveling, gold, potions, treasure chests
- Village with Elder Maren (quest line) and Tobb the merchant (shop)
- Minimap and quest marker
- Autosave in the browser
